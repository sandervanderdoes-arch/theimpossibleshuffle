# Mission merch

Print-ready T-shirt designs for The Impossible Shuffle.

| File | Design |
|---|---|
| `scoreboard.png` | "Final score: Mathematics 1, Humanity 0" |
| `professor.png` | Professor Factorial badge, "Delightful. Again?" |
| `odds.png` | "I tried anyway." with the exact 68-digit odds |
| `one-with-the-shuffle.png` | Card fan with "We have become one with the shuffle" |
| `preview.png` | All four on a dark shirt colour, for a quick look |

- 4500 × 5400 px (15 × 18 in at 300 dpi), transparent background: the standard size for
  Printful, Spring, Redbubble and most print-on-demand shops.
- Made for **dark shirts** (black, charcoal, navy, dark green). Flat colours, no glows or
  gradients, so they print cleanly with direct-to-garment printing.
- Fonts: Bungee and JetBrains Mono, both SIL Open Font License, which allows commercial use
  on merch.
